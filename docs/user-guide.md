# TokenPlume user guide

How to open sessions and read the Context River, Composition and lifespans views. For what the numbers mean and where they come from, see [data semantics](data-semantics.md).

## Opening a session

Open the printed localhost URL. The server binds only to `127.0.0.1` and never modifies session files. It also rejects any request whose `Host` (or `Origin`, when present) is not `127.0.0.1` or `localhost` on its own port, so a web page cannot use DNS rebinding to read session data. Returning to a recently viewed session displays its bounded browser-cached analysis immediately, then conditionally revalidates it in the background with the server ETag. A failed refresh leaves the valid cached view in place and shows a warning.

The picker offers **Harness: All harnesses / Pi / OpenCode / Claude Code** and combined title/directory search. Filtering does not switch the open session. Mixed results identify the recording application; an OpenCode child or a Claude Code subagent remains a separate session, not merged parent context. A Claude Code subagent is labelled **child session** followed by its subagent type. Portable `opencode-…` references contain no database path. Duplicate native IDs across databases are ambiguous and rejected rather than selecting an arbitrary copy.

## Context River interactions

Where comparable recorded Input is available, a dashed **Reported input** line and hatched **Unreconciled input** overlay extend the known stack to that value. Both grouping modes and vertical scales include the reference. Missing comparisons break the line; estimates above reported Input are never shrunk. The gap is an approximate difference—not recovered context items—and does not affect item counts, lifetimes, token-turns, Composition or cost attribution. See [design notes](../plans/archive/unreconciled-input.md).

- Move across chart space to move the nearest-call crosshair. Click empty chart space or a call label to pin call details while preserving the selected item; click a ribbon (or activate it with Enter/Space) to select a context item and pin its first included call, regardless of pointer position. This is its first appearance in model context, not necessarily the call that created its content. Ribbon selection does not automatically pan or zoom. Hover previews are supplementary.
- The toolbar shows the visible call range, equal-sized **‹ / ›** call-selection buttons, zoom controls, **Fit all**, and **Latest**. Stepping preserves the selected item (including when absent at the new pin) and zoom, nudging the target into view only near/outside a viewport edge. Without a pin, the fresh/Fit all overview starts Next at the first call and disables Previous; a zoomed/scrolled view steps from its nearest centre call. Use **← / →** to step calls, or **h / l** while the River workspace has focus. Text entry, composition/IME, modifier shortcuts and tab navigation retain their own keys; Composition does not intercept these call shortcuts. A compact **Go to call** field alongside the zoom controls pins the requested call, preserves the selected item and current zoom (including Fit all), and nudges it into view when needed. Manual range fields are removed; drag an area or use zoom controls instead. Escape in the call field cancels the entry without clearing the pin/item. Escape within View options closes that disclosure and restores summary focus.
- **View options** contains vertical scale and Items/Item types display. River uses one 500px-high layout (the former Balanced layout); older saved Compact settings are ignored without resetting other preferences. The chart's Y-axis shows readable stack-weight ticks and units. **Session scale** is the fresh default and keeps heights comparable across the session; opt-in **Visible calls** uses visible call columns plus interpolated viewport-edge samples, so ribbon heights change as you pan or zoom. Always read the current axis before comparing heights. When token geometry is unavailable, the axis explicitly describes structural placeholder weight rather than tokens.
- Range, pan, and pinch gestures are isolated in a small transition module. Pointer cancellation/lost capture, release outside the plot, window blur, and component teardown clear the gesture without leaving a stale drag or changing selection.
- The session summary keeps model-call count, context-item count, peak calculated context, and cost visible. **Cost** is the session's cost at API rates: each call's recorded cost, or an estimate at the provider's rate on the call's date, including calls covered by a subscription (such as a ChatGPT plan), which are priced at what they would have cost. It is not an invoice. Only when a session has both kinds of call does a line underneath split the cost into what was billed per token and what a subscription covered. Calls without a price and failed attempts are counted under the amount. Open **Session details** for both subtotals, the cost the harness recorded, Claude Code's own session total when its transcript records one (a running total that also includes subagents and Claude Code's own calls, so it is never added to the other figures), where the prices came from, provider usage, compactions, tokenization coverage, reconciliation, model/provider, and session metadata. Each call's details say how its cost was found: the rate used, when that rate started and how the date is known, and what the harness recorded. See [data semantics](data-semantics.md#cost-assessment) for the rules.
- Call and item panels keep key values and actions visible; usage breakdowns, token diagnostics, profiles, and technical identifiers use native disclosures. Copy buttons provide feedback for IDs.
- On wide screens, the Context River and full-session lifespan list share the main column. A compact, bounded sticky call/item inspector appears alongside them only when an item or call is selected. Content preview, estimate basis, diagnostics and identifiers remain independently available; section choices survive panel remounts within the session. **View details** deliberately reveals and focuses the selected item's summary inside that inspector; with no selection it focuses the inspector prompt. Hover and selection never open or scroll it implicitly.
- **Composition** is a separate tab that starts in **Cumulative** scope, with **At call** available for point-in-time estimates. Cumulative values are estimated token-turns: each present item's applicable estimate is added once per model call through the pinned endpoint, or across the whole session when unpinned. This measures input-context exposure, not unique content, provider usage, billed tokens, or cost. Treemap area and shares use available scoped estimates; missing and partial coverage stays qualified, while zero/unavailable/tiny contributors remain inspectable in the complete ranked **List**. Provider prompt counts, known request framing, and reconciliation details remain separate and are compared only at call scope.
- Lifespan browsing searches source labels and bounded previews (up to 120 characters), filters by item kind, and sorts by token-turn exposure, size, or first appearance. Size uses one shared token-estimate profile with the widest numeric coverage; missing estimates sort last. The call axis and compaction markers describe the full session independently of chart zoom. With no filters, the disclosure shows one total item count; filtered results show the available/total count. Click/tap a position on a lifespan segment to select its item and pin the nearest real call within that segment. Item-label clicks and keyboard Enter/Space select only the item, preserving the pin; items without call presence, including terminal summaries, remain selectable without inventing a call. These actions do not switch views or automatically pan/zoom River.
- **Copy view link** shares navigation through an unversioned v1 URL fragment: a compact session reference such as `pi-a83f9c2d71b4` (harness plus a hash of its native session ID), River/Composition view, River grouping (`display=items` / `display=itemTypes`, saved preference when omitted, with **Items** as the fresh default), Composition scope, approximate visible call range, pinned call and selected item. Reload and Back/Forward restore valid references; stale/inaccessible references produce feedback rather than fabricated selections. Ambiguous session references are rejected rather than selecting an arbitrary file. Pan/zoom updates replace the current history entry, while explicit navigation can add entries. Links carry opaque identifiers, not session content or local paths, and do not grant access or distribute the session. Other presentation settings stay local. Explicit URL grouping overrides stored grouping; missing or invalid values use the saved preference (or Items if none). Restoring links does not write preferences. Clipboard-denied browsers get a selectable manual-copy field; copied links omit URL credentials and unused query parameters. See [delivery notes](../plans/archive/shareable-view-links-notes.md).
- **Item types** uses a fixed semantic palette shared by grouped bands and their legend: User Message blue, Tool Result gold, Assistant Message teal, Compaction Summary lavender, with distinct colours for the other categories. These colours identify types, not cache status; individual-item colours and Composition remain ID-hashed and unchanged. Clicking or keyboard-activating a grouped band opens a viewport-bounded breakdown near that band, without scrolling the page; Escape/Close returns focus without scrolling. Moving the page or chart dismisses the breakdown, while its member list can scroll independently.
- **Selected item** identifies and outlines only the exact ribbon. Compaction lineage remains available through direct connectors, item details, and lineage actions; sibling sources are not treated as one visual selection group, and other ribbons stay at normal opacity.
- Press `Escape` to close an active disclosure/overlay first, including expanded **Cache & cost** (focus returns to its trigger). Subsequent presses clear the selected item, then the pin, then restore Fit all. **Clear selected item and pinned call** clears both at once.

The borderless **▸ Cache & cost / ▾ Cache & cost** disclosure starts collapsed for fresh preferences. Expand it for **Cache / Cost / Off** and **Tokens / Share (%)**; collapse/Off retains the last mode and cache view. Explicit River/economics preferences are remembered across sessions and reloads in one bounded, versioned localStorage entry (enums/booleans only; no session identities, content, selection or navigation). Choose **Session scale** and **Items** directly to restore the River defaults; there is no blanket Reset action. Blocked storage leaves the in-memory UI usable.

The **Cache / Cost / Off** track reports only policy-supported, provider-usage-derived cache buckets and each call's assessed cost. In Cost mode, API-equivalent costs are hollow, dashed marks in a separate colour, and a shaded bar marks a range. Cache ratios and cost are not assigned to individual items; unsupported, missing, partial, and measured-zero data remain distinct. The mode controls and compact legend sit beside the economics plot; its exact readout is a normal-flow chart footer that remains aligned while the River pans. The track keeps quantitative marks on the shared call axis and places compaction, target-change, and cache-share observations in a bounded event lane with explicit event counts, keyboard/touch details, and exact call mappings. Ribbon thickness and Composition use local item token estimates, not provider prompt totals. Genuinely unavailable token geometry is shown explicitly rather than replaced with serialized-byte weights. The legacy `displayWeight` field remains a serialized-byte diagnostic, never a token-geometry fallback. Image previews identify encoded source-data size (usually base64), not decoded image bytes. In individual-item River view, subdued colour-blended flows join summarized source bands to the summary's actual band; retained items continue unchanged. These overlapping flows show structural, lossy replacement—not conserved tokens or per-source contributions to the summary. Hovering/selecting a source emphasizes its connection; selecting the summary gently emphasizes its incoming flows. Grouped Item types view does not invent individual merge mappings, and terminal summaries without drawable call geometry do not acquire fabricated bands. These economics mappings are audited against Pi v0.78.0 adapters and should not be read as universal provider semantics.
